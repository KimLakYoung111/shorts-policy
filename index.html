Shorts Studio

Operated by Kim Lak Young (김락영)

Shorts Studio is a personal tool that helps create short-form videos (YouTube Shorts) from a topic. It writes a script, prepares background footage, generates narration and subtitles, and renders a vertical MP4 video.

After the operator reviews and approves a finished video, the tool uploads it to the operator's own YouTube channel through the YouTube Data API (YouTube API Services):

youtube.com/@김락영-p2o

The tool is not offered to the public. Only the operator signs in with Google.

This app uses YouTube API Services. See the Privacy Policy and Terms of Service.
